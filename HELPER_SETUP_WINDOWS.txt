Jasper's Music - YouTube Helper for Windows

What this helper does
The public website cannot directly run yt-dlp on your computer. This helper lets
the Key Finder page start a local analyzer at http://127.0.0.1:8765, so YouTube
link analysis runs on your own computer instead of the Render server.

First-time setup
1. Extract this zip folder.
2. Open PowerShell in the extracted folder.
3. Run:

   powershell -ExecutionPolicy Bypass -File ".\install_youtube_helper_dependencies.ps1"

4. Then run:

   powershell -ExecutionPolicy Bypass -File ".\install_youtube_helper_protocol.ps1"

5. Go back to the Key Finder page and click Start Helper.

After the first setup
Open the Key Finder page. If it says YouTube Helper offline, click Start Helper.
Your browser may ask whether you want to open Jasper Helper. Choose allow/open.

Notes
- Python 3.12 or a compatible Python 3 version must be installed.
- ffmpeg must be installed for audio conversion.
- Keep the helper PowerShell window open while using YouTube link analysis.
- Uploaded audio analysis can still run through the website without this helper.
