# Jam Tracks Hub v1.0.0

First stable release of Song Workspace.

## Highlights

- Local-first guitar song workspace
- Create and import chord charts
- Chords and lyrics editing
- Transposition and Smart Capo
- Original, Target, and Shape Key workflow
- Easy, Roman, and Nashville views
- Instrumental sections
- Chord Shapes and Shape Picker
- Read Mode and Performance Mode
- Zoom and line spacing controls
- JTH JSON, ChordPro, TXT, and Print/PDF exports
- Local browser persistence
- English and Traditional Chinese interface
- Legal and privacy boundaries for user-provided content

## Privacy

Song Workspace song content is processed and stored locally in the browser. Song titles, lyrics, sections, ChordPro source, JTH JSON content, and chord anchors are not sent to Jam Tracks Hub services by the workspace.

## Known / Deferred

- Final iPhone/iOS Safari hardware acceptance remains pending as post-release validation.
- Key Finder backend and provider architecture are unchanged in v1.0.0.
- Cloudflare-only Key Finder migration, Render retirement, and deeper WAF/rate/bot/cache hardening are planned for later work.

## Version Roadmap

- `v1.0.1`: small bug fixes and security hardening
- `v1.1.0`: larger backward-compatible architecture updates, such as Cloudflare-only Key Finder
