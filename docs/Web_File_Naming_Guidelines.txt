網頁檔案命名規範指南 (Web File Naming Guidelines)
==============================================

為了確保網站上傳到伺服器（如 Render）後，所有的下載連結與圖片都能正常顯示，請務必遵循以下命名準則：

1. 禁止使用特殊符號 (No Special Characters)
   - 絕對不要在檔名中使用： #, %, &, ?, +, @, $, !, *
   - 原因：這些符號在網址 (URL) 中有特殊功能。例如「#」代表網頁錨點，「?」代表參數。
   - 錯誤範例：W8_Backing_#m.pdf
   - 正確範例：W8_Backing_FSharp_Minor.pdf

2. 不要使用空格 (No Spaces)
   - 網頁伺服器不喜歡空格，空格會被自動轉換成像「%20」這樣的亂碼，導致連結失效。
   - 請使用「底線 _ 」或「連字號 - 」代替空格。
   - 錯誤範例：Weekly Track Vol 1.pdf
   - 正確範例：Weekly_Track_Vol_1.pdf

3. 建議使用英文字母與數字 (Use Alphanumeric)
   - 雖然現代伺服器大多支援中文檔名，但為了跨平台相容性與 SEO 考量，強烈建議使用英文與數字。
   - 正確範例：Jam_Tracks_Hub_Cover_01.jpg

4. 注意大小寫一致性 (Case Sensitivity)
   - 網頁伺服器（特別是 Linux 伺服器）是區分大小寫的。
   - 如果檔名是「Track.pdf」，HTML 寫「track.pdf」會導致找不到檔案。
   - 建議：習慣全部分小寫，或是維持固定的命名邏輯。

5. 與程式碼完全匹配 (Match HTML Code)
   - 檔案名稱必須與 index.html 或 tracks.html 中 href 屬性的內容一字不差。
   - 檢查重點：
     - 資料夾名稱是否正確 (例如 slides/)
     - 副檔名是否正確 (例如 .pdf, .jpg, .png)

遵循以上規則，可以避免 99% 的「電腦可以開，上傳後卻壞掉」的幽靈問題！
