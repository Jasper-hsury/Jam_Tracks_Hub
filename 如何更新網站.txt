如何更新 Jasper's Music 網站
==========================

這個網站目前的更新方式是：

修改本機檔案
→ 推送到 GitHub
→ Render 自動重新部署
→ 公開網站更新


一、打開專案資料夾
----------------

用 VS Code 打開這個資料夾：

C:\Users\Jaspe\OneDrive\桌面\Jasper's_Music_v1_with_find_key


二、修改網站內容
--------------

常見要修改的檔案：

首頁：
index.html

和弦 / Key Finder 頁面：
chords.html
chords.js
key-finder.js

Tracks 頁面：
tracks.html
tracks.js
tracks.json

網站樣式：
style.css

Python API：
api-server\app.py
api-server\detect_key.py


三、本機測試
----------

修改完後，先在 VS Code Terminal 跑：

cd "C:\Users\Jaspe\OneDrive\桌面\Jasper's_Music_v1_with_find_key"
powershell -ExecutionPolicy Bypass -File ".\start_render_local.ps1"

然後打開：

http://127.0.0.1:8000/index.html
http://127.0.0.1:8000/chords.html
http://127.0.0.1:8000/tracks.html

確認 API 是否正常：

http://127.0.0.1:8000/api/health

如果看到 status ok，代表 API 有正常啟動。


四、上傳更新到 GitHub
------------------

確認本機測試沒問題後，在 VS Code Terminal 依序輸入：

cd "C:\Users\Jaspe\OneDrive\桌面\Jasper's_Music_v1_with_find_key"
git status
git add .
git commit -m "Update website"
git push

如果只是小修改，也可以把 commit 訊息改成比較清楚的內容，例如：

git commit -m "Update chord page"
git commit -m "Fix key finder layout"
git commit -m "Add new track"


五、等待 Render 自動部署
---------------------

git push 成功後，Render 會自動偵測 GitHub 的更新並重新部署。

通常要等幾分鐘。

部署完成後，打開你的 Render 網站確認：

https://你的-render網址/
https://你的-render網址/chords.html
https://你的-render網址/api/health


六、常見問題
----------

1. 網站還是舊的

可能是 Render 還在部署，等幾分鐘再重新整理。
也可以用 Ctrl + F5 強制重新整理瀏覽器快取。


2. API offline

先檢查：

https://你的-render網址/api/health

如果這個網址打不開，代表 Render API 沒有正常啟動，要去 Render 看 Logs。


3. git push 失敗

先跑：

git status

如果有錯誤訊息，不要亂改，先把錯誤訊息複製下來再處理。


七、最短更新流程
--------------

平常最常用的流程就是：

修改檔案
測試本機網站
git add .
git commit -m "Update website"
git push
等待 Render 自動部署
